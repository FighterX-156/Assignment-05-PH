
1️⃣ What is the difference between var, let, and const?  
Ans: "var" can be redeclared and updated. "let" can be updated but not redeclared. "const" cannot be updated or redeclared.

2️⃣ What is the spread operator (...)?
Ans: The spread operator (...) spreads values from an array or object. It’s used to copy arrays/objects or add new values easily.

3️⃣ What is the difference between map(), filter(), and forEach()? 
Ans: "map()" returns a new array by transforming each item. "filter()" returns a new array with items that pass a condition. "forEach()" loops through items but does not return anything.

4️⃣ What is an arrow function?
Ans: An arrow function is a shorter way to write functions. Example: "const add = (a, b) => a + b;"

5️⃣ What are template literals?
Ans: Template literals make it easy to create strings with variables. Use backticks and "${variable}". Example:  `Hello, ${name}`
